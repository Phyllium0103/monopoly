- 顛倒陰陽陣交換雙方武力及防禦，僅作用於本場戰鬥。
- 移花接木陣交換兩城所有權；原主公的駐將和士兵移至交換後的城，繁榮度與地點保留。
- 不死圖騰只保護持有者麾下的人物，滿血復生，保留境界、修為、所屬及功法。
- 五行轉生丹與噬脈絕根符造成靈根不符時，功法回到原主公行囊。

## 觸發與回合

- 免戰牌及圖騰直接消耗，無需選使用者。原表能力／體力欄保留在來源快照，實際依使用者明確指定的直接使用規則處理。
- 替身符需要能力和體力達標的隨行使用者，只能抵消非戰鬥對主公發動的物品。敵方物品仍被消耗。
- 定身符／鎖仙陣從命中起封鎖物品，直到受害者下一個停留回合結束。
- 斂息符從使用當回合起計，共三個己方回合。風火輪保留至下一次遇到岔路。
- 傳音符可對選定己方城池免費、不限次調兵，直到關閉視窗。
- 平時斷腸毒丹與落日弓沿用傷害保留至少 1 血的處理。戰鬥毒傷也保留 1 血。
- 嗜血珠額外吸血持續五個戰鬥回合，涵蓋普通攻擊、功法技能、連擊與靈獸追擊。
