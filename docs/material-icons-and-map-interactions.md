# 材料圖示與地圖互動更新

18 種材料使用已選定的極簡平面透明圖：六類各三階。採用所有最新修正，包含龍鱗礦片／階梯銅晶、白金五環寶絲、白玉金紋蓮瓣仙玉，以及不是玉牌的太清法玉礦塊。

圖片以 256×256 WebP、品質 80、透明度無損壓縮，18 張共 220,006 bytes，相較原始 PNG 17,905,027 bytes 減少約 98.77%。不修改來源 PNG；來源／輸出 SHA 與尺寸記錄在 material-icon-assets.json。可用 scripts/import-material-icons.mjs 由選定素材重新匯入。

材料圖片顯示於：材料庫存及 10：1 合成配方／數量視窗、城池挖掘種類選擇及挖掘資訊、武將詳細卡片升階材料與武器升階確認視窗。所有網址透過 assetUrl 處理，可部署至 GitHub Pages 子路徑。

乾坤骰殿：下注結束或直接離開後均留在原道路格，保留來路與出口，下回合正常擲骰；不再隨機傳送或觸發其他落點事件。

山河社稷圖：真人抵達時先確認是否進入，暫不進入或關閉確認皆留在大地圖。確認進入後維持原本走滿16格、禁止道具、返回原入口的規則。AI 維持原本進入試煉的行為。

五行精靈：平時不動，點擊所在道路格才播放自己的四套動作之一；播放中忽略連點，不重新開始、不排隊。動作結束回到靜止，之後可以再次點擊。傳送選格期間優先處理傳送目的地。保留原本五輪生成／上限15隻／最終落點才消失／無獎勵／腳底對準格中心與地圖縮放。

驗證：npm run build、npm test。tests/map-interactions-materials.cjs 驗證骰殿位置與方向、山河圖確認、18圖映射、實際合成與所有武器材料階段；tests/elemental-spirits.cjs 驗證點擊時序、播放鎖定、不同格的動畫獨立、落點消失及 P2P 重播。
