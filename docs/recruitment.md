# 募兵司

地圖新增三間2×2募兵司，入口各對應兩格道路。西部(23,18)、中南部(36,35)、東北部(58,9)，未移動既有道路、城池、商店或16棟展示建築。三區依道路最近據點分別服務103、112、85格，距離單位是道路格，不是擲骰回合。

停在任一入口格才開啟募兵拉條，路過不觸發。每批100人，沿用既有士兵價格及主公技能折扣，取消不扣款，金額與位置在引擎再次驗證。一般擲骰前的徵兵按鈕及舊動作均已移除。AI保留原本的補兵門檻及每次2000人政策，但也只可在募兵司停靠時補充。

多人與單機共用相同Engine；新版地圖規則為map-recruitment-20261031。舊版房間會清楚提示所有玩家更新網頁並另建房間，不覆寫舊對局資料。沒有部署或修改Supabase函式。

## 模型

原生v20匯出檔保存在art-src/map-models/recruitment-v20.glb。selected版4,888,644 bytes；遊戲只載入一種Meshopt/WebP壓縮版recruitment-lod0-3ea35540f29c.glb，3,622,556 bytes，三棟共用快取與實例。

虎符細紋在一般減面候選中受損，因此這棟保留全部345416三角面索引，不減面；512px WebP貼圖、16位位置量化與材質批次合併降低檔案大小。原示意圖的逐像素一致性仍未宣稱通過。其他20類模型不重建。

離線重建工具：scripts/map-runtime-tools/add-recruitment.mjs（在該工具目錄安裝既有package.json依賴後執行；正常npm build不需要此工具）。

驗證：募兵司專用規則測試、既有地圖/展示建築測試、TypeScript與production build；未執行完整遊戲模擬套件。實際壓縮檔已解碼、檢查10×10地台並匯入live Blender查看；這不是瀏覽器完整操作驗證。
