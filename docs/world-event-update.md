# 九州風雲與比武大會更新（2026-10-06）

## 聽風樓與固定活動

- 每次造訪聽風樓有 20% 機率抽一名已出世、未出仕且未死亡的方外人物。方外名額最多一位；總候選最多四人，其餘由一般人物填補。
- 水鏡先生隨行時必定抽一名隱藏人物，候選包含未出世者。無可用候選時不出現；尚未出世的候選只有實際被抽到後才加入人物狀態。
- 仙人出世改為第 15、30、45…輪開始固定揭露兩位尚未出世人物，不足兩位則全數揭露。固定活動不進入隨機事件池與使用紀錄，同輪仍可正常抽九州風雲。
- 九州比武大會於第 20、40、60…輪結束、下一輪或限時結算之前舉行。

## 比武大會

- 存活主公隨機分組進行 1v1 半決賽，再由勝出勢力決賽；剩三位主公安排一位輪空，剩兩位直接決賽。
- 每場可重新選擇隨行人物（含主公），使用同一人物或換人。上場血量至少為上限的 10%，無可用人物或取消選擇視為棄權。
- 沿用單挑的攻擊、功法、靈獸與戰鬥物品規則，致命傷害保留 1 血並按認輸規則判定，人物不會戰死。
- 場間不呼叫血量或體力回復；體力沿用物品使用後的值。一般攻擊、功法技能依原戰鬥規則不另扣體力。
- 平手以剩餘血量比例較高者晉級，相同比例隨機抽籤；雙方棄權則該組沒有晉級者，決賽僅有一方時該方奪冠。
- 冠軍主公獲得一件天階上品（tier=11）功法、神器或寶衣，三類各占 1/3，直接加入行囊。

## 價格與其他事件

- 旅行商人商品五折。
- 商路暢通持續五輪，丹藥、陣法、符籙、法器、神器、寶衣、功法、靈獸均七折；涵蓋旅行商人，五折與七折相乘為原價 35%。招募、復活、拍賣與出售依各自原規則。
- 兵器庫開啟發放玄階下品至地階上品（tier=3…8）的神器或寶衣。
- 論道大會提供目前境界修為上限的 10%，經人物與隊伍修為加成後加入，不超過瓶頸；真仙無有限修為上限，冤魂不獲得修為。
- 招賢令與蝗災持續五輪。
