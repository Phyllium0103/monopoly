# 武將貼紙圖美術規定

所有武將頭像（`public/art/generals/*.png`）依這份規定生成，目的是讓一百多位角色看起來是同一個人畫的。
生圖時把這些規則寫進提示詞（英文版在 `style_spec.py`），再套上每位武將的個別設計。

## 構圖
- **Q 版 1.5 頭身**：頭約佔整體高度的三分之二，身體很小，沒有脖子，手腳短小。
- **朝向**：身體、臉與武器一律朝畫面**右側**（四分之三側面），方便對戰時把左邊的人水平翻轉、面對面。
- 站姿，兩隻手都看得見，兩隻腳都看得見。
- 外圍有一圈**白色貼紙邊**；背景是單一純色（洋紅或青色，之後去背用）。

## 臉
| 部位 | 規定 |
|---|---|
| 眼睛 | 兩顆**純黑實心圓點**，大小一樣，裡面沒有任何東西：**沒有反光、沒有亮點、沒有睫毛、沒有眼珠分層**。女性、老人也一樣是圓點。 |
| 眉毛 | 兩條短而粗的黑色色塊；凶的往鼻子方向下壓，平靜的畫平。 |
| 鼻子 | 一條很短的小弧線。 |
| 嘴巴 | 一條簡單小線；只有大喊時才畫成小的張嘴形狀。 |
| 臉頰 | 兩個小的粉紅色橢圓腮紅。 |
| 膚色 | 單一淡膚色，完全平塗，沒有陰影。 |
| 鬍鬚、鬢眉 | 純色色塊（黑、灰或白），不畫一絲一絲的毛。 |

## 頭髮
單一平塗色塊，只加兩條簡單的弧線，不畫反光、不畫髮絲。

## 線條
整個角色用**同一種粗度的深褐黑色外框**，內部細節用較細的線；每位角色的線條粗細一致。

## 衣服
- 只用**平塗色塊**：最多三種衣服顏色，再加一個金色點綴。
- 沒有漸層、沒有布料紋理、沒有刺繡、沒有圖案。
- 領口、袖口或下擺**最多一條**裝飾邊。
- **長袍**：右衽交領、寬袖、一條素色腰帶，加一個圓形扣環。
- **鎧甲**：幾片平塗護甲板，兩種顏色，最多三條線條記號。
- **陰影**：只用一層平塗的較深色（衣褶下方、下巴下方），不畫其他明暗。

## 手持物品
- 每位武將**只拿《全部武將武器名稱對照》表上的黃階武器**，其他物品都不畫。
- 只拿一件的人，另一隻手是空的、張開。要雙持的才畫兩件（例如劉備雙劍、大喬雙扇）。
- 武器畫得大、畫得清楚；平塗色彩，刀劍是灰銀色刀身加一道較亮的色條，木柄深褐色，護手金色。

## 特效
只用**兩三條平塗的彎曲飄帶**，單一色調（陣營色），不畫漸層、發光、粒子、星星。

## 陣營色
蜀：綠；吳：紅；魏：藍；群雄與隱世高人：各自的素色（紫、黃、褐、灰、白等）。

## 檔案
- 生成：896×896，去背後裁切置中並縮成 512×512，存成透明背景 PNG（200 色）。
- 檔名：武將代號（例如 `guanyu.png`），主公用 `liubei`、`caocao`、`sunquan`、`dongzhuo`。
