## 範圍與材質處理

- 原始模型由 `src/data/mapModels.ts` 載入，沿用目前採用的 GLB、UV、法線與紋理。新配色以貼圖亮度調節目標色，保留瓦面紋理明暗；原色模式關閉換色與範圍標示。
- 只複製預覽中的目標材質與需要遮罩的幾何資料；不覆寫來源 GLB，不產生三份模型幾何。
- 淬體武院的屋瓦與地面圓環共用材質，以模型原始高度限制屋頂範圍，地面圓環維持原色。
- 募兵司以高度限制上方軍帳布面，側邊布簾、虎首、招牌與地坪維持原色。
- 山河社稷圖使用玉石材質命名，不能僅依 `roof` 字樣判斷。畫卷下方的玉瓦屋面以材質、高度帶與朝上法線共同限制，排除畫卷、卷軸、山石及地面。
- 萬寶鑑定所依使用者補充，主瓦、次瓦與頂端採光玻璃頂都納入配色；保留材質原有的透明等屬性。
- 百草堂的透明溫室與非屋頂部件維持原貌。

## 局部驗證

僅執行 TypeScript 型別檢查、15 個模型的載入與對照生成、配色／原色切換、範圍目視核對和必要的修正驗證。未執行整套 `npm test` 或擴大測試矩陣。

此頁保留換色前原始模型與全部候選方案。使用者完成選色後，已依 `art-src/roof-colors/selection.json` 將八套選色寫入遊戲實際使用的模型；詳見 `roof-color-application.md`。現有 `src/ui/HelpView.ts` 技術問答及主公素材保留。
