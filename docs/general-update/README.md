## 已確認規則
- 聽風樓最多四名候選，方外人物最多一名，不以額外方外人物補空位。水鏡先生隨行時從全部尚未出仕且未死亡的方外人物抽一名，包含未由事件揭露者。首次實際出現時才加入角色狀態。
- 管寧啟動時只跳過當回合主動行動，加成作用於隨行人物（含主公）的所有修為來源，共五個自身回合，不可疊加重啟。
- 普靜每五個自身回合可召喚任何死亡的非主公一名，同時最多一名，需空出隨行名額。冤魂五個自身回合後消失；原人物狀態獨立，復活後移出召喚名單，既有冤魂到期才離開。

## 實作細節
- 所有能力指七項基礎能力（武力、防禦、血量、丹器符陣），不包含體力；同城條件必須相同主公、皆駐城於同一座城。孫堅與孫策雙方生效，其餘指定對象生效。
- 隨行效果只由存活、隨行的實體角色提供。隊伍內同類加成相加，價格減免最低為零，再乘陣營／世界事件倍率。主公修煉速度加成作用於全部修為來源，秘境人物不享受隨行加成。
- 物品保留仍付體力、仍獲得使用修為；升階只提高該次效果，不改原物品、能力門檻或體力需求，天品封頂。
- 劉備徵兵優惠在陣營優惠之後每名再扣 0.5 下品。曹操額外過路費按目前擁有城池數計算，與原城池數公式並存。
- 「境界加乘兩倍」使劉禪七項能力的境界倍率乘二；固定隨行，不可駐城、進秘境、留宗門或變賣。渡劫必成功，低階突破仍依正常機率。
- 製物與華佗復活共用方外神通操作，隨行時在己方擲骰前整備可用，不要求站在任何地點。製物種類等機率，品階依目前遊戲貨品抽選公式。體力回復 -90% 為每個自身回合回復 1.5，上限 -10 的人物初始體力為 90。
