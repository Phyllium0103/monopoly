# 丞相，這過路費比雷劫還狠！

*Chancellor, This Toll is Worse Than Heavenly Tribulation!*

三國 × 靈氣復甦 × 大富翁 —— Three.js 本地單人策略桌遊。

## 啟動

```bash
npm install
npm run dev       # 開發伺服器 http://localhost:5173
npm run build     # 型別檢查 + 打包到 dist/
```

開發時可用 `?lord=cao|sun|liu|dong` 跳過選擇畫面直接開局。推到 `main` 會自動部署到 GitHub Pages。

## 玩法

選擇 **曹操、孫權、劉備、董卓** 其中一位，其餘三位由電腦操控。所有人在依真實地理繪製的路網上輪流擲骰前進，每人開局持有 **3 上品**靈石。

- **爆擊**：擂台戰每次攻擊有 3% 機率爆擊（×1.5 傷害），擅長一擊制勝的武將機率更高。
- **空城**：城池至少要有一名駐將；駐將全部陣亡後城池變成空城，守軍回到主公身邊。
- **擲骰前**：使用物品、徵兵、調度駐軍、替武將裝備或卸下神器寶衣、學習功法。
- **岔路**：城池之間以道路與關隘（虎牢關、潼關、劍閣……）相連，洛陽、鄴城、長沙等樞紐有三四條路。移動方向固定：不走回頭路，連回合之間也一樣，遇到岔路口（標 🔱）才隨機轉向，只有開局出發方向是隨機的。四個角落的路上各有一座傳送陣，踩到會被隨機傳送。商店、聽風樓散布在各條要道上，秘境只有六處（太行洞天、華山仙境、泰山福地、廬山幽谷、峨眉金頂、東海仙島），分散在各地要道上，地圖上沒有死路。
- **靈脈**：地圖上有六處靈脈（標 💎），路過就能獲得靈石，不必停下；獎勵依主公本人的境界計算，每輪每位主公只領一次。
- **驛道奇遇**：停在驛道上約七成機率遇到奇遇——拾得靈石、義勇來投、散修贈丹、老道贈符、殘破陣盤，甚至荒廟壁畫裡的黃、玄階功法、古戰場的神兵；也可能遭山賊、盜賊或毒瘴。部分奇遇（受困商旅、山中棋局、關隘盤查）要玩家抉擇。
- **城池**：骰子點數停在無主城池時，遭攻打的城池繁榮度會下降 5%。骰子點數停在無主城池時，才能支付佔領費（高於該城過路費，繁榮度越高越貴），派 1～5 名武將和士兵駐守。踏入他人城池時，可以繳過路費，或發起戰鬥：
  - **擂台戰**：雙方各派一將單挑，每回合同時出手（先手者先出手），可能戰成平手（雙方得經驗、免過路費）（守方只能派該城的駐將應戰，沒駐將就無人應戰），能量滿時可施放功法技能，也能使用物品。血量低於 20% 減傷 30%；低於 10% 就會認輸（保住性命）；若被一擊直接打到歸零，武將當場戰死。
  - **煉丹／煉器／畫符／佈陣比試**：比較雙方武將的能力值（之後會換成小遊戲）。雙方各出 500 兵維持秩序，敗方 500 兵全滅，勝方也會折損。
  - **攻城戰**（第 11 輪起開放，前 10 輪只能比武、鬥法）：最多三將，並用拉條決定出兵多少，對上該城守軍。一名城池守軍約等於十名隨行士兵，武將屬性與陣法、符籙都會影響戰力。敗方兵力全滅，勝方也會折損；攻方打贏就奪下城池。
  - 戰敗要付 **雙倍過路費**。
- **秘境**：可選擇難度（煉氣、築基、金丹、元嬰、化神、煉虛、合體、大乘、渡劫共九級）與派遣人數（1–5 人），選錯可按取消重選。難度看境界不看戰力：境界相同歷時 3 回合，秘境比隊伍高越多越久（最長 9 回合）、越兇險，低則越快（最短 1 回合）。歸來時帶回 2～5 份神器、寶衣、丹藥、功法或靈獸。
- **商店**：地圖上六種商店各 5 間；天寶商行分陣法／符籙／法器三類各 10 種，天工坊分神器／寶衣各 6 件，藏經閣 10 本功法，萬獸園 8 隻靈獸，百草堂 12 種丹藥外加復活（自己的亡將減半價、境界降一階；其他主公的亡將降兩階、一次一人）。
- **鬥法與臨陣脫逃**：每座城池佔領時由城主指定一種鬥法，挑戰者只能用那種方式；被攻城時守方可臨陣脫逃，四分之一守軍倒戈加入敵方。
- **主公資料**：點擊頂部主公欄可查看任何主公的詳細資料；地圖上的彩色箭頭是各主公目前面向的方向。
- **復活**：武將戰死、渡劫身死或死在秘境後，可到百草堂花錢復活，或用還魂丹復活；破產主公麾下離開的武將則進入聽風樓。
- **模式**：開局可選最大回合數（20～100 輪，到時比總資產），或無盡模式（直到只剩一位主公沒破產）。
- **託管**：右上角「🤖 託管」可讓電腦暫時代打你的回合，隨時取消。
- **測試**：右上角「🧪 測試」可獲得大量靈石、士兵與所有物品。
- **士兵派遣**：徵兵、佔領城池、增派或撤回守軍、攻城出兵，都用拉條自己決定數量。
- **城池榜**：每座城池的繁榮度依東漢末年的實際盛衰各不相同（洛陽最繁華，武威最荒涼）。右上角「🏆 城池榜」可查看繁榮度、靈石收入、士兵收入、過路費、守城戰力的排名與總表。
- **電腦行動**：電腦每回合結束後，畫面中央彈出大方框，只顯示最後的行動結果（停在哪、佔領、購物、戰鬥……），點擊任意處立刻關閉；「📜 紀事」可開關天下紀事。
- **突破提示**：武將修為圓滿時，回合開始會提示前往突破，頂部主公欄與「👥 武將」按鈕會閃爍，名冊最上方會單獨列出可以突破的武將。
- **商店**：百草堂（丹藥）、天工坊（神器、寶衣）、藏經閣（功法）、萬獸園（靈獸，限一隻）、天寶商行（法器、陣法、符籙）、聽風樓（招募將領，一次一位）。
- **結束**：付不出錢時要割地賠款，玩家可自己選擇賣哪座城池（繁榮度 ×150）或哪名隨行武將（身價依能力與境界，賣出自動卸下裝備）；賣掉的武將進入聽風樓；城池與隨行武將都賣光仍付不清就破產出局。剩一位主公時直接勝出；否則到達最大回合數時比總資產（或選無盡模式一直打到只剩一人）。
- **陣營特色**：四個陣營各有擅長的經營模式（魏：修煉與謀略；蜀：城池經營與低價徵兵；吳：守城與過路費；群雄：擂台與攻城），各有長處與短處，選主公時可看到。
- **專屬被動**：各國約 40 位人物各有依歷史評價、陣營與戰力設計的被動，例如關羽「武聖」（擂台加傷、機率連擊、百毒不侵）、張遼「威震逍遙津」（作戰時兵力 ×2）、郝昭「陳倉之守」、馬謖「紙上談兵」（佈陣強但守城減弱）。
- **地貌**：每座城池依真實地理分為平原、山地、高原、沙漠、盆地、水鄉、濱海、丘陵、邊塞，影響靈石與士兵收入、守城戰力、駐守武將的靈氣與繁榮成長。例如水鄉富庶但難守、山地易守難攻且宜於修行、邊塞與沙漠盛產精兵。
- **宗門**：隨行武將最多十名（含主公本人），其餘留在宗門；要站在自己的城池上，才能調度隨行武將與駐軍。
- **九州風雲**：每 5 輪隨機掀起一場風雲事件，災難類第 20 輪之後才會出現。
  - 經濟：旅行商人（停在定點不限時，第一位走到的主公可交易，之後離開）、天降橫財、五穀豐登、天寶拍賣會（各自秘密出價，價高者得）、商路暢通、兵器庫開啟
  - 修煉：靈力爆發、天道垂青、五行輪轉、上古秘境現世、仙人出山（隱藏武將：左慈、于吉、華佗、水鏡先生、管輅、張仲景……）、靈潮湧動、隕星墜落、論道大會
  - 政治：天子詔令、流民歸附、招賢令
  - 災難：妖獸潮、天災地動、黃巾餘黨、乾坤大挪移、心魔劫、蝗災、瘟疫、洪水、軍中兵變、盜賊洗劫

開始畫面和遊戲中右上角都有「📖 說明」，可分頁查看完整規則。

操作：左鍵拖曳旋轉、右鍵平移、滾輪縮放、WASD 移動視角、空白鍵擲骰（或按右側的大圓鈕），擲完骰、處理完落地事件後回合自動結束。右上角可切換 1×／2×／4× 速度。

### 規則數值

| 項目 | 規則 |
| -- | -- |
| 靈石 | 下品、中品、上品、極品，1:100 自動換算 |
| 境界 | 凡人 → 煉氣 → 築基 → 金丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫 → 真仙。修為滿了進入瓶頸，需在武將名冊手動突破，可能失敗；金丹以上要渡雷劫 |
| 功法 | 天地玄黃 × 上中下 12 階，每個品階有金木水火土五種、每個屬性 5 種名稱；五行相剋（剋制方傷害 ×1.35）。每位武將一種，自廢修為才能更換 |
| 裝備 | 20 種神器、20 種寶衣，各 12 個品階；除了武力、防禦、血量，還有煉丹、煉器、畫符、佈陣加成；每兩階提高一個裝備境界需求（最高化神） |
| 武將 | 四位主公本人也是武將（不能駐守城池、不能派去秘境、不能變賣，戰死即敗北）；另有 13 位隱藏武將，只有「仙人出山」事件才會現身（每次 3 位，聽風樓最多同時列出 2 位）|
| 物品 | 丹藥看煉丹、法器看煉器、符籙看畫符、陣法看佈陣。每件物品都有能力值門檻與體力消耗，威力越強越高；多數分黃玄地天四階 |
| 過路費 | 繁榮度^1.2 × 7；同一主公城池越多越貴 |

## 程式架構

```text
src/
├── data/        generals（將領）、items（物品、功法、靈獸）、board（城池與路網）
├── game/        GameState、Game（主流程）、TurnManager、Currency、types
├── systems/     General、City、Battle、Item、Shop、Realm、RoadEvents、Event、AI
├── world/       World、Terrain、CityMesh、Buildings
├── character/   CharacterSprite（紙片人）
├── scene/       SceneManager、CameraController、Environment、Animator
└── ui/          GameUI、Dialog、GeneralsView、ShopView、BattleView、Screens
```

`systems/` 和 `data/` 不依賴 Three.js 或 DOM，可以直接拿來跑模擬或做伺服器端驗證。
