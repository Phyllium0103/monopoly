# 武將名冊與共用行囊

## 設計參考

參考 Red Dot 2017 得獎作品 [Quantum Break Interface](https://www.red-dot.org/project/quantum-break-interface-16557-16557)。獎項介紹強調簡潔的選單與 HUD，以及兩者一致的設計語言。本作採用清楚的資訊層級與固定操作區，配合既有的墨綠、暖金和國風人物圖；未使用參考作品的圖像資產。

## 名冊

- 所有武將在同一張清單，不另分可突破／隨行／駐城區塊，也不固定主公第一。
- 位置排序：隨行 → 城池繁榮度由高至低 → 外出 → 宗門。其他排序依對應能力由高至低。
- 血量、修為、體力同列顯示；仙衣與功法兩格保持在列中央。
- 點選武將開啟獨立詳情彈窗，分成人物與天賦、身心狀態、戰鬥與四藝、裝備及操作。不再使用境界圖片外框。
- 主畫面隨行頭像下補修為條，最高境界顯示滿條。

## 20 格共用行囊

- 仙衣與未修習的功法共用 20 格。窄螢幕換行，容量不變；格子位置會儲存。
- 點物品拿起，圖示取代滑鼠箭頭；再點目的格放入。不支援拖曳。
- 可裝備格發亮，空格不顯示加號。不能放入時保留原物品與選取狀態，顯示原因。
- 仙衣可卸回空格、交換或移給其他武將；已修習功法不可自由卸下，彈窗內的自廢操作沿用原有代價。
- 滿格時禁止購買、競標與增加行囊件數的卸裝。獎勵與強制退回物品先等待選擇，再替換未裝備物品或放棄。
- 所有物品轉移先驗證再執行；取消、錯格、門檻不足與重複動作不移動物品。
- 仙衣與功法使用一致的浮動資訊卡，名冊仙衣說明不顯示價格；功法屬性與能力分行。

規則版本：`roster-inventory-20261112`。不相容舊對局，需重新開局。
