# 仙途三國

三國 × 靈氣復甦 × 大富翁 —— Three.js 本地單人策略桌遊。

## 啟動

```bash
npm install
npm run dev       # 開發伺服器 http://localhost:5173
npm run build     # 型別檢查 + 打包到 dist/
```

開發時可用 `?lord=cao|sun|liu|dong` 跳過選擇畫面直接開局。推到 `main` 會自動部署到 GitHub Pages。

## 玩法

選擇 **曹操、孫權、劉備、董卓** 其中一位，其餘三位由電腦操控。所有人在環狀跑道上輪流擲骰前進。

- **擲骰前**：使用物品、徵兵、調度駐軍、替武將裝備神器寶衣或學習功法。
- **城池**：骰子點數停在無主城池時，才能支付佔領費，派一名武將和士兵駐守。踏入他人城池時，可以繳過路費，或發起戰鬥：
  - **擂台戰**：雙方各派一將回合制單挑，能量滿時可施放功法技能，也能使用物品。
  - **煉丹／煉器／畫符／佈陣比試**：比較雙方武將的能力值（之後會換成小遊戲）。雙方各出 500 兵維持秩序，敗方 500 兵全滅，勝方也會折損。
  - **攻城戰**（第 11 輪起開放，前 10 輪只能比武、鬥法）：最多三將加上所有未派遣的隨行士兵，對上該城守軍。一名城池守軍約等於十名隨行士兵，武將屬性與陣法、符籙都會影響戰力。敗方兵力全滅，勝方也會折損；攻方打贏就奪下城池。
  - 戰敗要付 **雙倍過路費**。
- **秘境**：派三名武將探索 5 回合，可能隕落。歸來時依屬性帶回神器、寶衣、丹藥、功法或靈獸。
- **港口出海**：沿江、沿海的港口城池（標 ⚓）可派武將出海。海外貿易帶靈石經商、數回合後獲利歸來（可能遇海盜或船難）；尋訪仙山比秘境兇險，但獎勵更好，還可能得仙人點化。
- **商店**：百草堂（丹藥）、天工坊（神器、寶衣）、藏經閣（功法）、萬獸園（靈獸，限一隻）、天寶商行（法器、陣法、符籙）、聽風樓（招募將領，一次一位）。
- **結束**：付不出錢時，先從繁榮度最低的城池開始變賣（守軍回到主公身邊）；城池賣光仍不夠，隨行武將才會隨機離開（進入聽風樓）抵債；只剩主公一人仍付不清就破產出局。剩一位主公時直接勝出；否則 40 輪後比總資產。
- **地貌**：每座城池依真實地理分為平原、山地、高原、沙漠、盆地、水鄉、濱海、丘陵、邊塞，影響靈石與士兵收入、守城戰力、駐守武將的靈氣與繁榮成長。例如水鄉富庶但難守、山地易守難攻且宜於修行、邊塞與沙漠盛產精兵。
- **宗門**：隨行武將最多十名，其餘留在宗門；在聽風樓、無主城池或自己的城池可以調度。
- **九州風雲**：每 5 輪隨機掀起一場風雲事件，災難類第 20 輪之後才會出現。
  - 經濟：旅行商人、天降橫財、五穀豐登、天寶拍賣會（各自秘密出價，價高者得）
  - 修煉：靈力爆發、天道垂青、五行輪轉、上古秘境現世、仙人出山（左慈、于吉、華佗、管輅）
  - 政治：天子詔令、群雄會盟
  - 災難：妖獸潮、天災地動、黃巾餘黨、乾坤大挪移、心魔劫

開始畫面和遊戲中右上角都有「📖 說明」，可分頁查看完整規則。

操作：左鍵拖曳旋轉、右鍵平移、滾輪縮放、WASD 移動視角、空白鍵擲骰、Enter 結束回合。右上角可切換 1×／2×／4× 速度。

### 規則數值

| 項目 | 規則 |
| -- | -- |
| 靈石 | 下品、中品、上品、極品，1:100 自動換算 |
| 境界 | 凡人 → 練氣 → 築基 → 金丹 → 元嬰 → 化神。修為滿了自動嘗試突破，可能失敗 |
| 功法 | 天地玄黃 × 上中下 12 階、五行相剋（剋制方傷害 ×1.35）。每位武將一種，自廢修為才能更換 |
| 物品 | 丹藥看煉丹、法器看煉器、符籙看畫符、陣法看佈陣。能力值要達到門檻，使用會消耗體力 |
| 過路費 | 隨繁榮度加速成長；同一主公城池越多越貴 |

## 程式架構

```text
src/
├── data/        generals（40 名將領）、items（物品、功法、靈獸）、board（環狀地圖）
├── game/        GameState、Game（主流程）、TurnManager、Currency、types
├── systems/     General、City、Battle、Item、Shop、Realm、AI
├── world/       World、Terrain、CityMesh、Buildings
├── character/   CharacterSprite（紙片人）
├── scene/       SceneManager、CameraController、Environment、Animator
└── ui/          GameUI、Dialog、GeneralsView、ShopView、BattleView、Screens
```

`systems/` 和 `data/` 不依賴 Three.js 或 DOM，可以直接拿來跑模擬或做伺服器端驗證。
