# 已選地圖整合 · 2026-10-19

正式資料來自使用者瀏覽器匯出的「三國路網-可編輯設計 (9).json」。原始資料保存在 public/art/map-selected/layout-source.json，沒有還原已刪除的城池或礦脈。

- 300個四連通道路格、33城、47設施、18岔路、11回路。
- 每格4世界單位；建築占地8×8，GLB原10×10地台縮放0.8；道路實體寬3.76、間隙0.24、厚0.64。
- +X東、+Z南，北方在-Z。上側建築門朝+Z，右側門朝-X。所有事件停在門前第一個道路格判定，建築不占道路。
- 正交相機從西南向東北，方位45°、相對水平面俯角30°，禁止旋轉；拖曳平移、滾輪縮放。「全圖」可框住整片菱形地台，「純地圖」可暫時收起遊戲UI。
- 使用原選綠金底圖原檔，擴鋪為280×280正方形平面，透過45°相機投影為菱形，沒有把道路或建築烘焙到底圖。
- 白玉／冰青兩種原選道路貼圖，保持獨立格子、倒角和厚度；根據棋子實際所在格更新，含移動、傳送、多人棋子及離格恢復。
- 13種原生Blender GLB原樣複製，來源與SHA見model-manifest.json。同類模型只載入一次，依材質合批並用InstancedMesh重複擺放。
- 城池外觀依目前繁榮度：<20荒地、20–39聚落、40–59小鎮、60–79大城、80–89高塔、90以上仙城；這只改外觀，不更改原有繁榮成長／經濟公式。
- 六間已完成商店不改檔；乾坤骰殿與六階城池採用最新精修候選，仍保留其草稿狀態。礦脈、秘境、山河社稷圖沒有獨立Blender成品，使用遊戲既有對應3D靈礦／秘境／傳送造型，按2×2占地縮放。
- 五個乾坤骰殿都可由道路到達；社稷圖沿用原傳送規則，現在會在五個骰殿間隨機選擇，避免總送第一處。

## 多人與交付界線

客戶端與本機權威引擎共用同一份新BOARD。禁止把舊房間數字格號直接映射到新地圖：進入舊配置房間會明確拒絕，保留原對局，不會默默覆寫。線上部署需同時部署新前端及重新build:engine的權威引擎，再建立新房間。這次不會自行發布線上服務。
