# 武將數值、技能與平衡研究

日期：2026-10-06（台北時間）

> 本文保留當時評估資料。其後已更新劉禪成長、兀突骨加成、管寧及左慈冷卻，現行規則見 [商店與武將更新](shop-and-general-update.md)。

## 範圍與判讀方式

逐一檢視目前程式的175位人物：蜀42、吳40、魏40、群雄40、方外13。資料來源是 `src/data/generals.ts`、`src/data/passives.ts`，並對照 GeneralSystem、BattleSystem、CitySystem、ItemSystem、RealmSystem、GeneralAbilities、ShopSystem、Game 中的實際運作。

本文件是設計建議。本次實作是關羽開局隨行、法正開局留守宗門，以及天工坊（使用者稱天工閣）神器與寶衣各10件；其餘能力和技能維持目前設定，供挑選後再改。

結論来自資料與公式分析，沒有模擬勝率或進行遊玩測試。「較強／較弱」描述用途和機制，不是已實測的勝率排名。候選調整數值仍需實際遊玩後校準。

### 基準

- 基礎七值順序：武力／防禦／血量／煉丹／煉器／畫符／佈陣。三國人物目前全部從凡人開始（包含呂布），方外人物從金丹開始。
- 靈根每次建立人物皆隨機；種子表中的固定靈根欄位不能當作目前實際靈根。廢靈根無功法，天靈根吐納快20%；普通五行需匹配功法。
- 武、防、血境界倍率：1／1.2／1.6／2.2／3／4／5.2／6.6／8.2／10／12。四藝按1＋境界×0.1成長。
- 下表「當前境界裸裝武/防/血」包含自身無條件被動，但不含裝備、功法、同城羈絆、隨行光環、陣營特色、世界事件、心魔、臨時狀態。條件技能另列。金丹人物不能直接與凡人裸裝數值作同境界排名。
- 綜合戰力為武×2＋防＋血/5，未評估先手、閃避、減傷、控場、經濟與隱藏招募。因此目前售價和AI戰力不完全反映技能價值。
- 一般暴擊基礎3%，倍率1.5：額外12%暴擊僅約增加6%未計其他互動的平均單擊傷害。連擊15%則約增加15%普通攻擊次數，不適用技能。
- 「必定先手」是一方有、另一方沒有時，每個戰鬥回合先出手；雙方都有先手時同時出手。先手可能讓敗方無法還擊，價值高於單純小幅武力。
- 守城正面兵力與守城加成取最高值；負面守城加成相加。城池靈石、士兵收入則可由多名駐將相加。不同類型技能不能都當作可加總。
- 使用物品修為＝實際消耗體力×3，再乘修為被動。因此省體力同時減少單次用物品的修為；保留物品並不保留體力；升階只提升效果、不提升使用門檻。
- 秘境死亡率由境界差、隊伍人數與隕落被動決定，不看武、防、血；高武不代表探索高境界秘境安全。

### 先改善機制，再調整能力值

1. 保留著名戰將的高武力；把決策放在出手時機、護主、追擊、撤退，不讓每個人都只加傷害。
2. 將謀士從通用比試百分比區分成規則選擇、預留策略、資訊、改造物品。四藝高依然是使用高階物品的門檻。
3. 守將分為撐住第一擊、延長戰線、保兵撤退、反制物品、欺敵資訊、恢復城池六種用途。
4. 羈絆最好給兩人不同分工；同城「所有能力+20%」會使兩位隨行角色被迫一起留城，功能受限。
5. 主公真仙直接獲勝，所以全隊／主公修煉加成應與戰鬥傷害分開評估。曹操還有陣營修為+15%，孫權有-5%。
6. 新技能建議先有明確一次／三輪／五輪上限、明確消耗、失敗代價；免費創造物品或資產的效果特別要避免循環。

### 機制連動提醒

- 三名商品折扣角色（魯肅、曹洪、李肅）合計45%；商路七折時天寶購價=原價×0.55×0.7=38.5%，低於目前回收價50%。旅行商人五折疊商路也是35%。這已是可以買入後回售的價差；新增商人技能前宜先決定回收依成交價還是原價計。
- 劉禪「擂台不死」僅免死亡，仍會在低血量認輸；九州比武本來就全員不死，因此此被動在比武中不額外保證晉級。
- 劉禪必定成功作用於雷劫，凡人到煉氣、煉氣到築基仍走一般低階突破機率。其基礎30／30／300，凡人實際裸裝60／60／600，四藝也60。
- 方外人物金丹四藝有1.3倍率，易跨過高階物品使用門檻。比試使用四藝再加技能，不宜把方外99與普通99當作實際相同。
- 普靜冤魂可用任何已死亡非主公人物，最多一名、無裝備功法、不能獲修為；原人物復活後，已召魂仍留至到期。不能把它當作真的免費復活。
