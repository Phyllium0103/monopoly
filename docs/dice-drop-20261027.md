# 立體掉落骰子

遊戲的 `GameUI.rollDice()` 使用原生 Blender 製作的玉白骰子 GLB，從螢幕上方掉落，交由 Rapier 0.21.0 模擬翻滾、碰撞與自然落定，再顯示步數。頂面對應 Engine 傳入的數值，不重新擲骰或改動遊戲規則。支援單骰、雙骰、額外步數與倍數。

## 資源

- `public/art/dice/ivory-recessed.glb`：808,436 bytes，27,416 triangles，22 meshes，3 PBR materials，無外部貼圖。
- 真正圓角外殼與 21 個凹槽／凹面色漆；1、4 為朱紅，其餘為深黑。
- 實體寬度 16 mm；瀏覽器以一致的單位邊長呈現。
- GLB 座標：+Y=1、−Y=6、+X=3、−X=4、+Z=2、−Z=5。
- SHA-256：`f36d1a9a1dca9722c7dbd595b6daca910753e4caeda0553d406a6e16268280eb`。
- 原生 `.blend`、建模腳本、獨立重開／GLB 回載報告及瀏覽器證據保存在工作資料夾 `outputs/real-dice-drop-20261027`。

## 動作與生命週期

Three.js 播放實際 Rapier 剛體模擬的狀態；GLB 保存骰子本體，不包含烘焙動畫。舊預設曲線、手動反彈與落地轉向已移除。

- 固定物理步長 1/480 秒、重力 −9.81，圓角立方體碰撞體（內核半寬 .425＋圓角 .075）、固定平面、CCD、接觸摩擦／恢復係數 .65／.32。
- 使用一致的遊戲尺度；16 mm 原模型在展示中正規化為單位邊長。碰撞體是均勻圓角立方體近似，不逐一計算點數凹槽對質量的微小影響。
- 起始角度、角速度及線速度來自 `crypto.getRandomValues`；啟動後不施加指定結果的力、不改角度／位置／速度，也不根據時間額外加阻尼。
- 兩顆骰子在同一個物理世界中互撞，直到全部真正進入睡眠且平躺。歪立、堆疊或範圍過大的候選不展示，改用另一組起始條件。
- 先完成物理計算，再播放完整軌跡。為相容既有單機及 P2P 權威結果，播放開始前用一個固定的立方體對稱旋轉，選擇模型的起始點數朝向。此旋轉從第一格到最後一格不變，也保持對稱碰撞體不變；不是落地後把數字或骰子轉到指定面。
- 相機在播放前依整段物理路徑設定固定構圖，不追逐／搬動骰子。渲染只內插相鄰物理取樣。依最新要求，原速／2×／4× 分別以物理時間的 2×／4×／8× 播放，不放大物理時間步長，也不以最低動畫長度限制倍速。
- 減少動態效果模式直接顯示這次模擬的落定姿勢。
- 落定後只顯示骰子本體，下方不顯示點數／步數卡；保留讀屏器結果播報與內部權威點數計算。

渲染器、模型與物理引擎延遲載入；停止後不持續執行動畫。等待房主只顯示「擲骰中」，收到結果才掉落；取消、重置、重疊請求都會結束前一個 Promise。分頁隱藏會跳過／結束展示，避免背景房主的 rAF 暫停卡住回合。模型、物理引擎或 WebGL 不可用時只顯示原本結果文字，不以舊假動畫代替，不阻止遊戲繼續。

## 驗證

- `npm run test:dice`：六面朝向／對面合計七、GLB 實際凹槽面向與點數、步數加成、數字備援與背景／取消生命週期；並執行 24 組真正 Rapier 模擬，檢查自由落體、接觸、自然睡眠、六種結果、固定模型對稱及每格未被轉向／搬動。
- 本次固定種子測試共 40 次雙骰接觸；模擬長度 2.92–4.32 秒。地面穿入容許量小於邊長 1.5%（數值接觸誤差），沒有後製向上搬動掩飾。
- 全部既有遊戲測試通過，正式建置通過。
- 原生工程已在第二個 Blender 程序真正重開，GLB 已實際重新匯入，尺寸及三角形一致。
- 實際瀏覽器已檢查六面、八張動作分鏡、單／雙骰、四倍速、多人等待、取消；遊戲實際擲出 5 點後繼續走路與事件。
- 本機開發預覽：`/dice-preview.html`，可選頂面及拖曳真實物理軌跡進度；預覽擲骰會保留落定畫面，遊戲內仍自動收起。
